## 解釈契約

- MALLOC `ALLOCATED`はlive allocation、`FRAG SIZE`はallocatorが保持するcapacityであり、特定のElwindUI objectへ帰属させない。
- IはJと同一のUIElement/state構成でpaint callbackのみを無効化するため、H→IをUI tree/layout/state、I→Jをrender tree/CALayer/paintの比較として読む。
- `vmmap`値は各sampleの実プロセスから採取する。Physical FootprintとRSSは同じプロセスのrender-stats JSONから採取する。
